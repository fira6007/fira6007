## 👋 About Me

I’m Firaol, a software engineer and fourth-year Software Engineering student. I focus on backend architecture, distributed systems, and real-time applications, while still enjoying the product work needed to turn solid systems into usable experiences. Most of my work starts with dependable data models, clean APIs, and reliable message flow, then carries that same attention into responsive web and mobile interfaces. I’m especially interested in software that solves concrete operational problems and stays understandable as it grows. I like the kind of work where reliability, maintainability, and interface clarity all need to hold up together.

## 🌍 What I Build

- **Campus information platforms** that help updates move clearly and quickly through busy student environments.
- **SMS gateways** with queues and retry handling for communication flows that need to remain dependable when delivery is imperfect.
- **Digital showrooms for local businesses** that make products easier to browse, compare, and trust online.

I like building software that balances reliability behind the scenes with straightforward, responsive interfaces for the people using it. That usually means staying practical: choosing tools that fit the problem, keeping systems observable, and avoiding complexity that does not improve the product.
